# 01 產品目標、主要使用者、MVP 範圍與採用假設

## 1. 產品目標

1. **規劃**：為多個投資組合設定定期定額計畫（每週、每月、指定日期），清楚看到每期預計投入的金額與標的。
2. **記錄**：記錄每一筆實際投入，包含價格、數量、手續費、股利與其他費用。App 不扣款，所以到期時只產生「待確認」紀錄，由使用者補上實際成交資料。
3. **總覽**：用台幣（可切換美元）看全部投資組合合併後的總資產、累計投入、損益、平均成本、報酬率，以及全期間的月損益走勢。
4. **觀察**：每天整理台股與台灣 ETF 的外資動向和官方重大訊息，產生可追溯的觀察名單，作為使用者自行研究的起點，不是買賣建議。

### 非目標（明確不做）

連接券商、下單、自動扣款、推播通知、投資日期提醒、iCloud 備份、資料匯出、Android、桌面網站版、社群功能、目標價或價格預測。

## 4. 已確認需求（第一輪回覆：「照建議」）

| 題目 | 確認結果 |
|---|---|
| Q1 發布範圍 | 先自用或少數人（TestFlight），之後再評估公開上架 |
| Q2 後端與預算 | 接受小型雲端後端（約 0～20 美元／月）；行情先用免費或官方來源，缺漏時手動；LLM 不指定廠商，用抽象層包起來；投資紀錄只存在手機本機 |
| Q3 基金 | 只做台灣可申購的境內與境外基金；MVP 以手動淨值為主 |
| Q4 交易類型 | 支援賣出、碎股與零股、股利再投入；分割與合併用手動調整；移動平均成本法；報酬率同時顯示含股利與不含股利 |
| Q5 定期定額與幣別 | 到期產生「待確認」紀錄並補產生漏掉的期數；遇休市順延到下一個交易日（每個計畫可改成提前）；美元檢視把全部資產換算成美元，同時顯示原幣金額 |

## 5. 採用假設（請確認，可修改）

| # | 假設 | 理由 |
|---|---|---|
| A1 | 本位幣固定為 TWD；第二檢視幣別為 USD；JPY 資產在兩種檢視中都換算，另外顯示原幣 | 符合「台幣總覽與美元原幣」，且讓日幣也有地方顯示 |
| A2 | 「月資料點」取每個月最後一個日曆日的估值；當月則取今天 | 能涵蓋全部期間，也能處理休市日 |
| A3 | 歷史月底價格與匯率由後端提供；缺漏時往前取最近一筆可用值，並標示「推估」 | 損益圖需要歷史估值 |
| A4 | 「累計投入」等於買入金額加上手續費與交易費用，減去賣出時回收的成本；股利不算投入 | 符合一般投資人的直覺；細節見 02 |
| A5 | 美股、日股手續費以原幣記錄；也可另外輸入台幣費用（例如複委託最低手續費以台幣收取的情況） | 複委託常見做法 |
| A6 | 觀察名單只在台股交易日產生；非交易日顯示上一個交易日的名單，並標示資料日期 | 外資資料只有交易日才有 |
| A7 | 每日觀察名單由後端集中計算，每台裝置下載同一份結果；App 不在本機呼叫 LLM | 保護金鑰、控制成本、確保結果一致 |
| A8 | 觀察名單的命名，由「買入／賣出觀察」改為「偏多訊號觀察／偏空（避開）訊號觀察」 | 降低被認定為買賣推介的風險（見 08）；已確認 |
| A9 | 後端不收集任何個人投資資料，App 呼叫後端時不帶持股內容（價格查詢只帶代號清單） | 隱私考量；且沒有 iCloud 備份需求 |
| A10 | 最低支援 iOS 17 | 可使用 Swift Charts 等新版 API；已確認 |

假設 A1～A10 已於第二輪確認（2026-11-18，回覆「照建議」），全部照上表採用。

## 6. 第二輪確認結果（2026-11-18，回覆「照建議」）

| # | 問題 | 確認結果 |
|---|---|---|
| R2-1 | 上市（TWSE）個股外資資料若需付費或授權 | **MVP 先只做上櫃外資資料加官方重大訊息**；上市標的列為「資料不足」。同時向 TWSE 洽詢官方取得管道（V1），取得授權並確認費用後，再決定是否啟用 |
| R2-2 | Face ID | 提供**選用**的 Face ID 解鎖，**預設關閉**；4 位數密碼永遠可以作為備援，重設密碼仍只能用復原碼 |
| R2-3 | 複委託手續費幣別 | 依**實際收費幣別**記錄（原幣或台幣都可以，`fee_currency` 欄位）；換算時優先用交易日匯率，沒有就用目前匯率並標示 |
| R2-4 | 美股、日股行情月費 | **MVP 不付費**。美股：使用者在設定頁輸入**自己的**個人 API 金鑰（App 直接呼叫，存在 Keychain，不經後端轉發，以符合個人用途條款），沒有金鑰就手動；日股與日本 ETF：手動輸入。付費方案留到階段 6 再評估 |
| R2-5 | 換手機會遺失資料（R-SEC-1） | **維持原需求：不做 iCloud 備份、不做匯出**。首次設定時以明確畫面告知「換手機或刪除 App，資料無法找回」，並要求使用者勾選確認。加密本機備份檔**不列入**範圍 |

> 註：R2-4 讓美股價格改由 App 直接向第三方 API 取得，等於使用者自己的 API 金鑰會存在手機的 Keychain 裡。這是使用者本人的金鑰，與「LLM 金鑰不可放在 App」的原則不衝突，因為 LLM 金鑰屬於服務方。
