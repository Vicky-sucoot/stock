# 03 畫面規格、首頁順序與主要流程

## 1. 導覽結構（Tab Bar）

| Tab | 內容 |
|---|---|
| 首頁 | 合併總覽（見下方首頁順序） |
| 組合 | 投資組合列表 → 單一組合 → 持有部位 → 交易紀錄 |
| 記錄（＋） | 快速新增：買入／賣出／股利／費用／分割調整 |
| 觀察 | 每日觀察名單 |
| 設定 | 密碼與復原碼、幣別與口徑、手動價格與匯率管理、資料來源與免責說明 |

## 2. 首頁畫面順序（由上而下）

1. **頂部列**：標題「總覽」、幣別切換 `[TWD | USD]`（預設 TWD，會記住上次的選擇）、更新狀態「最後更新 11/18 16:05・行情資料日 11/18」與重新整理按鈕
2. **定期定額計畫卡（優先顯示）**
   - 待確認期數（紅點）：「3 筆待確認，約 NT$15,000」→ 點進去到待確認清單
   - 近 7 天即將到期的計畫（日期、組合、標的、金額）
   - 本月預計投入合計與已確認投入
3. **資產 KPI 卡**：總資產（大字）；累計投入；損益與報酬率（可切換含股利／不含股利）；今日變動（若有）
4. **月損益折線圖**：全部期間、每月一點；兩條線：市值與累計投入；可切換顯示損益線；點選後顯示該月數值與資料來源（推估值以虛線或空心點表示）
5. **匯率卡**：USD/TWD、JPY/TWD 的現值、近 12 個月走勢小圖、資料日與來源、「手動」標記；「換算方式說明」連結
6. **資產配置**：依市場（台／美／日／基金）與幣別的環圈圖
7. **投資組合列表**：每個組合的市值、損益、報酬率；點進去看該組合
8. **持有標的平均成本列表**（可收合）：代號、名稱、數量、平均成本（原幣）、現價、報酬率
9. **資料狀態列**：使用估計值或缺漏的項目數，點進去看明細

> 觀察名單**不放在首頁**，避免和個人資產資訊混在一起，被誤解為針對持股的建議；它放在獨立的「觀察」Tab。

## 3. 主要畫面規格

### 3.1 解鎖畫面
- 4 格密碼點；數字鍵盤；「忘記密碼？使用復原碼」
- 連續錯誤 5 次後鎖 1 分鐘，之後逐次加長（見 10）

### 3.2 投資組合詳細頁
- 標頭：市值、投入、損益、報酬率（檢視幣別），附原幣小字
- 分段：持有部位｜定期定額計畫｜交易紀錄｜股利
- 持有部位列：代號、名稱、市場旗標、數量、平均成本、現價（標示「手動」或「延遲」）、市值、損益

### 3.3 定期定額計畫編輯
欄位：組合、標的（搜尋代號或名稱，或手動新增標的）、每期金額或數量、幣別、頻率（每週／每月／指定日期）、日期設定、休市處理（順延／提前）、開始日、結束日、預設手續費（固定金額或費率，加上最低收費）、備註。
底部預覽：「接下來 6 期：2026/12/01、2027/01/04（因 1/1 休市順延）…」

### 3.4 新增或確認交易
欄位：類型、日期、標的、價格、數量（支援小數到 6 位）、成交金額（自動計算，可改）、手續費、交易稅、其他費用、幣別、交易日匯率（選填）、備註。
如果是確認待確認紀錄，會預先帶入估計值，並以灰字提示。

### 3.5 股利
類型：現金股利（可輸入預扣稅、二代健保、匯費）、股票股利（增加數量）、再投入（同時產生買入）。

### 3.6 手動價格與匯率
- 標的頁、匯率卡都有「手動設定」：輸入值、生效日（預設今天）、備註
- 手動值旁邊有「手動」標籤，同時顯示「自動來源最新值：xxx（日期）」，供對照
- 只有使用者自己能改：可以「修改手動值」或「改回自動」，App 不會自動解除

### 3.7 觀察名單（見 06）
- 頂部：資料日期、產生時間、資料完整度（例如「上櫃 ✔、上市 ✖ 待查、重大訊息 ✔」）、免責聲明（固定顯示，可收合，不可移除）
- 兩個區塊：偏多訊號觀察（預設 5，「展開至 10」）、偏空／避開訊號觀察（同上）
- 第三個區塊：「訊號衝突／資料不足」（只列出代號與原因，不給方向）
- 每列：代號、名稱、上市或上櫃、總分、外資分、訊息分、一句理由；點進去看明細
- 明細頁：原始外資數據表（近 10 個交易日：買進、賣出、買賣超股數、估計金額、成交量占比）、資料日期、來源連結；相關訊息列表（標題、來源、發布時間、連結、判定、信心度、判定理由）；評分計算過程逐行列出

## 4. 主要流程

### 4.1 首次啟動
1. 歡迎與免責說明 → 2. 設定 4 位數密碼（輸入兩次）→ 3. 顯示復原碼，並要求使用者確認已抄寫（再輸入其中 4 個字元驗證）→ 4. 建立第一個投資組合 → 5. 新增第一個標的或計畫（可略過）→ 首頁

### 4.2 每日開啟
解鎖 → 補產生待確認期數 → 背景更新行情與匯率（不阻擋畫面，顯示進度）→ 首頁。更新失敗時顯示上次資料與錯誤原因，提供重試。

### 4.3 確認定期定額
首頁待確認卡 → 待確認清單 → 選一筆 → 補上實際價格、數量、手續費 → 確認 → KPI 重算

### 4.4 忘記密碼
解鎖頁「忘記密碼」→ 輸入復原碼 → 驗證成功 → 設定新密碼 → **產生新的復原碼**（舊碼作廢）→ 資料完整保留

### 4.5 查看觀察名單
觀察 Tab → App 向後端下載當日名單（快取）→ 查看明細 → 點來源連結，以 Safari View Controller 開啟官方或新聞原頁
