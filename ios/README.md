# iPhone App（第三階段）

| 目錄 | 內容 | 驗證方式 |
|---|---|---|
| `DCACore/` | 計算核心（第一階段） | CI：Linux 上的 `swift test` |
| `DCAKit/` | App 邏輯：`DCASecurity`（密碼、復原碼、鎖定、Face ID 設定）與 `DCAKit`（資料保存、投資組合、定期定額、交易、手動值、總覽、行情更新） | CI：Linux 上的 `swift test` |
| `App/` | SwiftUI 畫面、Keychain、Face ID（只能在 Mac 的 Xcode 建置） | **尚未編譯驗證**：需要 Mac |

## 在 Mac 上建置與安裝到 iPhone
需要：macOS、Xcode 15 以上、Apple ID（實機安裝需 Apple Developer 帳號或免費的個人開發簽章）。

```bash
brew install xcodegen
```
```bash
cd ios/App && xcodegen
```
```bash
open DCAApp.xcodeproj
```
1. 在 Xcode 的 Signing & Capabilities 選擇你的 Team，並把 bundle ID（`project.yml` 中的 `com.example.dca`）改成你自己的
2. 選擇模擬器或連接的 iPhone，按 Run
3. 第一次建置會從 GitHub 下載 swift-crypto 套件

套件測試（Mac 或 Linux 皆可）：
```bash
cd ios/DCAKit && swift test
```

## 第三階段已完成的功能
- **首次設定**：免責說明 → 4 位數密碼（拒絕 0000、1234 等）→ 顯示復原碼並核對其中兩組 → 勾選資料保存說明 → Face ID（選用，預設關閉）→ 建立第一個投資組合
- **解鎖**：連續錯誤 5 次起鎖定 1 分鐘並逐次延長；改系統時間無法縮短鎖定；不會因錯誤次數清除資料；切換 App 時遮住畫面，離開超過設定時間後重新上鎖
- **忘記密碼**：用復原碼重設密碼，**投資資料完全不動**，並產生新的復原碼、舊碼作廢
- **投資組合**：新增、編輯、封存、刪除（需輸入密碼）、是否納入總覽
- **定期定額**：每週、每月、指定日期；月底規則；遇休市順延或提前；開始日早於今天時可選擇是否補產生；即時預覽接下來 6 期
- **待確認**：開啟 App 時補產生漏掉的期數；確認時補上實際價格、數量與費用；可略過；刪除該筆交易後回到待確認
- **交易**：買入、賣出（防止賣超）、現金股利、股利再投入、股票股利、費用、分割調整；複委託手續費可用台幣並填交易日匯率
- **首頁**：定期定額卡 → 總資產與損益（台幣／美元切換、含或不含股利）→ 月損益圖（推估月份另外標示）→ 匯率卡 → 資產配置 → 投資組合 → 平均成本 → 資料狀態與來源標示
- **手動值**：價格、淨值、匯率可手動設定，自動更新不會覆蓋，只有使用者能改回自動
- **行情**：台股與台灣 ETF 直接取自證交所、櫃買中心 OpenAPI（免費，至少間隔 6 小時）；美股使用你自己的 Finnhub 金鑰（選用）；日股、基金、匯率暫時手動

## 與規格的差異（第三階段的決定）
| 規格 | 實作 | 原因 |
|---|---|---|
| 本機 SQLite（GRDB） | 單一 JSON 檔（原子寫入、`completeFileProtection`、排除備份），金額以字串保存 | 個人資料量小；可在 Linux CI 完整測試；之後有需要再換 SQLite |
| App 只呼叫後端 | 免費方案下 App 直接呼叫官方 OpenAPI；後端網址設定後自動改用後端（`AppModel.backendURL`） | 使用者選擇免費方案，目前沒有部署後端主機 |
| 交易日曆 | 尚無官方休市表來源：只排除週末，並在畫面標示「日曆未更新」 | 來源待查（docs/07 V5） |

## 尚未驗證或待補
- `App/` 的 SwiftUI 程式碼**還沒有在 Xcode 編譯過**，第一次建置可能需要修正編譯錯誤
- Keychain、Face ID、檔案保護、切換 App 遮罩等只能在實機或模擬器上測試
- Finnhub 回應欄位依官方文件慣例撰寫，正式使用前需查核
