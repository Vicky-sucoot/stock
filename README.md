# 定期定額投資管理 App（iPhone）— 產品規格

> 狀態：**規格草案 v0.1，待使用者確認**｜撰寫日：2026-11-18｜外部資料查核日：2026-11-18（台灣時間 2026-11-19 凌晨）
> 本倉庫目前只有規格文件，尚未開始寫程式。

## 一頁式產品摘要

| 項目 | 內容 |
|---|---|
| 產品 | iPhone 專用、繁體中文的「定期定額投資規劃與記錄」App |
| 範圍 | 台股、台灣 ETF、美股、美國 ETF、日股、日本 ETF、台灣可申購之境內／境外基金 |
| 不做 | 不連接券商、不下單、不自動扣款、不推播、不提醒投資日、不做 iCloud 備份、不匯出資料 |
| 主要使用者 | 使用者本人（階段 A：自用或少數親友，以 TestFlight 散布）；之後評估公開上架（階段 B） |
| 核心價值 | 1）多個投資組合合併後的資產、投入與損益，一眼看清<br>2）定期定額到期自動產生「待確認」紀錄，不漏記<br>3）每日台股外資動向與公司重大訊息的觀察名單，每一筆都能追溯到來源 |
| 首頁 | 定期定額計畫（待確認優先）→ 合併總覽 KPI（預設台幣，可切換美元）→ 月損益折線圖 → 匯率與換算 → 投資組合列表 |
| 安全 | 4 位數 App 密碼鎖，加上首次設定時產生的復原碼；重設密碼不會刪除本機資料 |
| 推薦架構 | 原生 iOS（SwiftUI，本機用 SQLite 存放投資紀錄）＋ Python FastAPI 後端（只處理公開市場資料與 LLM 分析）＋ PostgreSQL |
| 最大風險 | ①TWSE 上市股票的「個股外資買賣超」不在 TWSE OpenAPI 內，取得管道待查<br>②財經新聞授權尚未取得<br>③公開上架時，觀察名單可能構成「證券投資分析建議」 |

## MVP 功能清單（階段 A）

**投資組合與紀錄**
- [ ] 建立、編輯、封存、刪除多個投資組合
- [ ] 定期定額計畫：每週／每月指定日／指定日期清單；月底規則；遇休市順延
- [ ] 到期自動產生「待確認」紀錄；開啟 App 時補產生漏掉的期數
- [ ] 交易紀錄：買入、賣出、股利（現金／再投入）、費用、分割調整
- [ ] 基金單位數、碎股、零股（小數數量）
- [ ] 移動平均成本法；已實現與未實現損益；報酬率分「含股利」與「不含股利」

**資產、行情與匯率**
- [ ] 合併總覽：總資產、累計投入、損益、平均成本、報酬率；台幣與美元切換
- [ ] 全期間月損益折線圖
- [ ] 開啟 App 時更新行情與匯率，顯示最後更新時間與資料日期
- [ ] 手動覆寫價格、淨值、匯率，自動更新不會蓋掉
- [ ] 匯率走勢與換算說明

**每日觀察名單（台股與台灣 ETF）**
- [ ] 偏多觀察與偏空／避開觀察，各預設 5 檔，可展開至 10 檔
- [ ] 外資及陸資買賣超篩選：連續買超、單日大幅買超、連續賣超、單日大幅賣超
- [ ] 公司重大訊息（官方）利多／利空分類；財經新聞待授權確認後才啟用
- [ ] 每個標的顯示：原始外資數據、資料日期、來源連結、相關訊息來源連結與發布時間、評分依據、理由；資料不足或衝突時另外標示

**安全**
- [ ] 4 位數密碼、復原碼、重設密碼時保留資料、背景切換時遮罩畫面
